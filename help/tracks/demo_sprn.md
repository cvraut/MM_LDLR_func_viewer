This file is `help/tracks/demo_sprn.md`. Each track can have its own help file named after the track file without its extension.

Write what the assay measures, how the data was processed and how to interpret it. For example:

- **Assay:** a made-up screen, shown as −log₁₀ p per 50 bp window.
- **Hits:** windows with −log₁₀ p ≥ 3, drawn in the row underneath.
- **Scale:** SPRn, SPRi and SPRa share one y-axis range (`autoscaleGroup: 'spr'` in `tracks.config.ts`) so heights are comparable.
